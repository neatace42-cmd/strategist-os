# Iterate an ad

1. Never iterate on a loser. Confirm the ad is a winner or close in the latest `reports/weekly/` (CPA and ROAS
   together, at meaningful spend). If not, say so.
2. Diagnose with `playbook/metrics.md` (weak hook? weak hold? low CTR? fatigue?). Name the element to PROTECT
   (what is clearly working).
3. Propose 3 iterations, one variable each, mixing a quick win and a bigger swing:
   - quick wins: new hook (first 1–3 s), an age-matched new face, a headline banner, tighter pacing;
   - bigger swings: format swap (UGC → authority explainer), this ad's winning hook stitched onto another winner's
     body, a desire swap (same story, different "why"), a new persona with the same angle.
4. For each: what changes, what stays, the hypothesis, the new ad name (version +1), the Studio format.
5. On approval, write each as a brief (angle-to-brief skill) and log it in `testing/testing-log.md`.
