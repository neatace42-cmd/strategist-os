# Angle to brief

1. Read: the idea-bank entry (or angle A## in `research/glp1-market-research.md` §9.3), `personas/personas.md`,
   `personas/voice-of-customer/README.md`, `strategy/roadmap.md`, `playbook/method.md`, `playbook/claims-guide.md`.
2. Fill `briefs/_brief-template.md` exactly. Customer words first (verbatim, with source), then a format to carry
   them (the Studio's formats: ugc, drama, adrama, song, static, native).
3. Write the hypothesis with the template; set the evidence band honestly.
4. Hooks: 2–3 that differ in picture AND words. For women 40+: clear over clever, calm "permission" openers on cold
   traffic, show the problem (hair tie, drain, part line) rather than only say it.
5. Script: the Studio's table (Time / Character / Visual action / Dialogue), about 2.8 spoken words per second.
6. Run the compliance checklist; list flags for the owner. No invented testimonials or numbers.
7. Name the ad (`playbook/naming-convention.md`). Save it in the current sprint's `briefs/` (or `briefs/`), and add a
   row to `testing/testing-log.md` with status "planned".
