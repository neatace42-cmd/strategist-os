# NutraEssence Strategy Brain

My personal creative-strategy workspace for **My Nutraessence** (pumpkin seed oil + saw palmetto).
It takes research all the way to a **finished ad brief**. Production is not done here: briefs go to NutraEssence Studio,
which is a separate app and repo.

> **Status:** Phase 0 (foundation) is built and waiting for my approval. See `running-notes/build-status.md`.
> **Mode:** a personal test. `reference/parker-brain/` is third-party, noncommercial-licensed material kept only for
> study (see `reference/README.md`). Anything that ends up in real ads is written in my own words.

## How the work flows

```
research ─► personas + customer voice ─► strategy (roadmap) ─► angle / idea bank ─► evaluation ─► sprint plan ─► BRIEF
   ▲                                                                                                              │
   └──────────────── weekly report · iterations · testing log · learnings  ◄──── ads run (Studio makes them) ◄─────┘
```

## Folders

| Folder | What lives there |
|---|---|
| `brand/` | Intake answers, product card, brand rules (the north star and the "never do" list) |
| `research/` | The GLP-1 market research (my master doc) plus a part-by-part index |
| `competitors/` | One folder per rival plus `_competitive-set.md` |
| `personas/` | Personas, sub-avatars and `voice-of-customer/` (customer words, sorted) |
| `strategy/` | The roadmap: diagnosis, 3 priorities, roads not taken |
| `idea-bank/` | Every idea, one file each, plus the evaluations |
| `sprints/` | Each round of concepts: sprint plan, its briefs, the retro |
| `briefs/` | The brief template (and finished briefs outside a sprint) |
| `testing/` | Testing log, open questions (loops), hypotheses, results |
| `reports/weekly/` | Monday reports |
| `data/` | My exports: Meta/Dolphin CSVs, review CSVs |
| `playbook/` | My method in plain English: method, metrics, claims guide, naming, learning path |
| `running-notes/` | Build status, decisions, what's missing, refresh dates, routine log |
| `reference/` | Read-only study material (Parker Brain) |

## Phases (each needs my OK before the next)

0. **Foundation** (folders, intake, playbook, data format, learning path)
1. **Research**: competitors, voice of customer, personas, gaps, open questions
2. **Strategy**: the roadmap
3. **Ideas to briefs**: idea bank, evaluation, sprint plan, briefs
4. **The loop**: weekly report, iterations, hook audit, testing log

## Using it

Open this folder in Claude Code (or a claude.ai/code session on this repo) and ask in plain words, for example
"run Phase 1 competitor snapshots" or "turn angle 1 into a UGC brief". Claude follows `CLAUDE.md`.
