# Testing

- `testing-log.md`: one row per test. Open it when the ad goes live, close it with the result and the learning.
- `open-loops/`: questions worth testing (scored), from every research doc's "Open questions".
- `hypotheses/`: a promoted question written as a falsifiable hypothesis with a test plan.
- `results/`: the outcome of each test: validated · invalidated · inconclusive · not enough data, plus a re-check date.
